# G5 — AWS production application: PASS

BatteryMindDemo runs in us-east-2 (ECS Fargate ARM64 image `v14`, RDS PostgreSQL + pgvector, Cognito with
required MFA, CloudFront, S3). The web app has working Assistant, Decision history and Evaluation views.

Executed live on `v14` (`tests/e2e/run_live.py`, all checks PASS; evidence `reports/performance/live-performance.json`):
MFA login, session and assessment writes with Bedrock explanation, Titan embeddings, semantic recall, chat,
cross-user denial, anonymous and oversized-input rejection, ECS task replacement, deletion, usage metrics.

- Region: PASS — chat (`google.gemma-3-12b-it`) and embeddings run on-demand in us-east-2; IAM allows only those
  us-east-2 foundation models. (An earlier `us.` Nova inference profile could route out of region and was removed.)
- RLS on RDS: PASS — schema is now applied at startup and queries run as a non-bypass role.
- Browser-driven showcase interaction test: PASS (`tests/browser/showcase.mjs`, real Chrome)
- SQS → EventBridge Pipe → ECS ingestion → S3 promotion: PASS (`reports/data_quality/aws-ingestion.json`)
- CloudWatch alarms: PASS (API 5xx/task count, RDS CPU/storage, DLQ depth deployed and queried live)
- OpenTelemetry tracing: PASS — the API exports OTLP spans to a pinned CloudWatch agent sidecar, which sends them
  to AWS X-Ray; 4 live requests produced 4 X-Ray traces (`reports/performance/otel-traces.json`, image `v14`).
- Security tests: PASS — `tests/security/` (token forgery, impersonation header, route auth, input, CORS) and
  `infra/aws-cdk/tests/test_security.py` (network, encryption, IAM scope, Cognito, tracing sidecar).
- CI: PASS — GitHub Actions re-downloads and checksum-verifies the NASA archive, re-runs ingestion and exports,
  and runs lint, unit, security, PostgreSQL, CDK and browser tests (first green run: commit `ab727d2`).
- Live end-to-end suite on image `v14`: PASS — including MFA, Bedrock, pgvector, concurrency, isolation,
  correction/deletion and persistence across an ECS task replacement.
- GitHub Actions OIDC deploy role: BLOCKED — an AWS Organizations SCP denies IAM OIDC provider creation for the
  project account role; deployments are run manually from reviewed `cdk diff` output.
- Image scan: `v14` is built from the latest `python:3.12-slim`; ECR reports 5 HIGH
  findings in Debian base packages (glibc x2, zlib x2, apt) with no fixed package versions. The affected code
  paths are not used by this workload; rebuild when upstream fixes are published.
