technical architecture

The public showcase uses validated, versioned exports only. Production credentials, authenticated memories, and private operational data never cross the publishing boundary.

Production request path

React client→CloudFront + private S3→Cognito→HTTPS ALB→ECS Fargate API→Private RDS PostgreSQL + pgvector

System boundaries

Scientific data

Immutable NASA source archives, SHA-256 manifests, deterministic Parquet transformations, preserved source indices, units, missingness, and quality flags.

Decision intelligence

Cutoff-aware capacity and SOH analysis, degradation trends, baseline RUL evaluation, and a versioned experimental decision policy.

Memory

User-owned sessions and evidence references with row isolation, historical cutoffs, correction supersession, deletion, optimistic concurrency, and idempotency.

Asynchronous work

SQS and DLQ feed bounded Fargate workers. Bedrock inference and embeddings return explicit unavailable states when model access is absent.

Security and operations

Network

No NAT gateway. Tasks use public egress, accept API traffic only from the load balancer, and reach private RDS through task-scoped security groups.

Access

Cognito authentication, least-privilege IAM, Secrets Manager, encryption, private S3 origins, GitHub Actions OIDC, bounded retries, quotas, and retained logs.

Region

All deployable configuration defaults to US East (Ohio), us-east-2. Account and AWS Projects home Region checks precede SCP diagnosis.

Evidence

Implementation, local validation, deployment, and live verification are recorded separately as PASS, FAIL, or BLOCKED with commands and artifacts.
